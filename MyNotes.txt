
image: postgres:16 — tells Docker "download and run version 16 of Postgres" (it'll pull this automatically the first time).

environment — sets the username, password, and database name that get created automatically when the container starts. 
    You'll use these to connect from Python later.

ports: "5432:5432" — maps the container's internal port to your actual machine, so tools outside Docker (like your Python script) 
    can reach it.

volumes — this is what makes your data survive even if you stop/restart the container. Without it, every restart would wipe the 
    database clean.

Using ports:
      - "5544:5432" since 5432 was already taken...probably by my local postgres


test_connection.py is just a sanity check — it opens a connection using the exact credentials from your docker-compose.yml, prints a success 
    message, then closes it immediately.
